## ✨ Özellikler

- 🃏 **Akıllı Kartlar (Flashcards):** Leitner sistemine dayalı algoritma ile eserleri ve kilit anahtar kelimeleri hızlıca ezberleyin.
- ⚔️ **Gerçek Zamanlı Düello:** Arkadaşlarınızla veya rastgele rakiplerle anlık eşleşerek edebiyat bilginizi yarıştırın, EP ve rank kazanın.
- 🔥 **ÖSYM Sever:** Son 10 yılın sınavlarında en çok sorulan ve soru gelme ihtimali en yüksek "Banko" eserlerden derlenen özel mod.
- 📝 **Dönemsel Testler:** Geçiş Dönemi'nden Cumhuriyet'e kadar 8 farklı ana edebiyat dönemine özel 4 şıklı sorular.
- 🎯 **Ruh Hali & Odaklanma:** Çalışma temponuza ve motivasyonunuza göre uyarlanan dinamik öneriler ve mikro hedefler.
- 📱 **Mobil & Web Uyumlu:** Web üzerinde PWA ve Android tarafında Capacitor ile tam responsive deneyim.

---

## 🏛️ Kapsanan Edebiyat Dönemleri

- **Geçiş Dönemi** (Kutadgu Bilig, DLT, Atabetü'l-Hakayık, Divan-ı Hikmet)
- **Divan Edebiyatı** (14. yy - 18. yy Nesir ve Nazım Başyapıtları)
- **Halk Edebiyatı (Âşık & Tekke)**
- **Tanzimat Edebiyatı** (1. ve 2. Dönem)
- **Servet-i Fünun & Fecr-i Ati**
- **Milli Edebiyat Dönemi**
- **Cumhuriyet Dönemi** (Saf Şiir, Toplumcu Gerçekçiler, Garip, İkinci Yeni, Modernist Roman ve Tiyatro)

---

## 🛠️ Teknolojiler

- **Frontend:** Next.js, React, TypeScript
- **Stil & Tasarım:** Tailwind CSS, Lucide Icons
- **Mobil Çatı:** Capacitor (Android APK)
- **Ses & Efekt:** Web Audio API tabanlı dinamik SFX sistemi
- **Dağıtım:** Vercel

## 🚀 Yerel Geliştirme (Local Setup)

Projeyi yerel ortamınızda çalıştırmak için:

```bash

# Bağımlılıkları yükleyin
pnpm install
# veya
npm install

# Geliştirme sunucusunu başlatın
pnpm dev
# veya
npm run dev
